# 경력기술서

## 프로젝트 1: 간편결제 그로스 최적화

- **기간**: 2023.03 - 2023.12 (10개월)
- **소속**: ABC 핀테크 / 결제서비스팀
- **역할**: Senior Product Manager (프로젝트 리드)
- **팀 규모**: 백엔드 4명, 프론트엔드 2명, 디자이너 1명, QA 1명

### 프로젝트 개요
간편결제 서비스의 월 거래액이 정체되어, 데이터 기반 그로스 전략을 수립하고 실행하는 프로젝트를 주도했습니다. 결제 퍼널 분석부터 A/B 테스트 프레임워크 도입, 전환율 최적화까지 전 과정을 리드했습니다.

### 주요 성과
- **월 거래액 150억 → 230억 달성** (53% 성장)
- **결제 전환율 12% → 18% 개선** (50% 향상)
- A/B 테스트 실험 주기 2주 → 3일로 단축
- 결제 포기율 25% 감소

### 담당 업무
1. Amplitude로 결제 퍼널 분석, 드롭오프 포인트 5개 식별
2. 가설 수립 및 우선순위 결정 (ICE 스코어링)
3. A/B 테스트 프레임워크 설계 및 개발팀과 협업하여 구축
4. 20+건의 실험 설계, 실행, 분석
5. 결제 UX 개선안 기획 (1-click 결제, 간편 인증 도입)
6. 주간 실험 리뷰 미팅 운영 및 이해관계자 보고

### 사용 도구/방법론
Amplitude, SQL, Figma, Jira, A/B Testing, ICE Framework, 스크럼

## 프로젝트 2: 소셜 커뮤니티 추천 알고리즘 개선

- **기간**: 2021.06 - 2022.03 (10개월)
- **소속**: XYZ 테크 / 프로덕트팀
- **역할**: Product Manager
- **팀 규모**: ML 엔지니어 2명, 백엔드 3명, 프론트엔드 1명, 디자이너 1명

### 프로젝트 개요
소셜 커뮤니티 앱의 콘텐츠 추천 품질이 낮아 사용자 체류시간과 리텐션이 하락하는 문제를 해결하기 위해, ML 팀과 협업하여 추천 알고리즘을 개선하는 프로젝트를 기획하고 실행했습니다.

### 주요 성과
- **추천 콘텐츠 CTR 8% → 15% 향상** (87.5% 개선)
- **사용자 체류시간 25% 증가**
- **D7 리텐션 5%p 향상**
- MAU 30만 → 50만 기여

### 담당 업무
1. 사용자 행동 데이터 분석으로 추천 품질 문제 정의
2. ML 팀과 협업하여 추천 모델 요구사항 정의
3. 평가 지표 설계 (CTR, 체류시간, 다양성 지수)
4. 단계적 롤아웃 전략 수립 (5% → 20% → 50% → 100%)
5. A/B 테스트 운영 및 결과 분석
6. 경영진 보고 및 투자 결정 지원

### 사용 도구/방법론
Mixpanel, SQL, Python (기초 분석), Jira, Confluence, A/B Testing

## 프로젝트 3: 신규 수익화 모델 런칭

- **기간**: 2022.01 - 2022.08 (8개월)
- **소속**: XYZ 테크 / 프로덕트팀
- **역할**: Product Manager
- **팀 규모**: 백엔드 3명, 프론트엔드 2명, 디자이너 1명, BizDev 1명

### 프로젝트 개요
MAU 80만 달성 후 수익화가 필요했으나, 사용자 경험을 해치지 않는 수익화 모델을 찾아야 했습니다. 구독 모델과 네이티브 광고 두 가지 수익원을 기획하고 런칭했습니다.

### 주요 성과
- **월 매출 0원 → 5억원 달성** (8개월)
- 구독 전환율 2.5% 달성 (업계 평균 1.5%)
- 광고 CPM 3,500원 달성
- 사용자 만족도 점수 유지 (NPS 45 유지)

### 담당 업무
1. 벤치마크 조사 (국내외 유사 서비스 10+개 분석)
2. 사용자 인터뷰 20건으로 지불의향 조사
3. 프라이싱 전략 수립 (A/B 테스트로 최적 가격 도출)
4. 구독 페이월 UX 설계
5. 광고 SDK 연동 및 네이티브 광고 포맷 기획
6. BizDev 팀과 광고주 유치 전략 수립
7. 수익/사용자경험 트레이드오프 모니터링 대시보드 구축

### 사용 도구/방법론
Amplitude, SQL, Figma, Jira, Notion, A/B Testing, 프라이싱 테스트
