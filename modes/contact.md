# 링크드인 아웃리치 메시지 생성 (contact)

이 모드는 타겟 기업의 채용 담당자나 PM 리드에게 보낼 링크드인 메시지를 생성합니다.

## 한국 비즈니스 커뮤니케이션 톤

한국 링크드인 메시지는 서구권보다 격식을 갖추되, 과하게 딱딱하지 않아야 합니다:
- **존칭 사용**: "님", "~하시는", "~해 주시면 감사하겠습니다"
- **간결함**: 3-5문장 이내
- **구체적 관심**: 기업의 특정 제품/기능에 대한 관심 표현
- **겸손한 자기소개**: 자기PR이 아닌 "함께 이야기 나누고 싶다"는 톤
- **부담 없는 마무리**: "편하실 때 커피챗 가능하시면 좋겠습니다"

## 메시지 유형

### 1. 채용 담당자에게 (Recruiter)

```
안녕하세요, {이름}님.

{기업명}의 {직무명} 포지션에 관심이 있어 연락드립니다.
저는 {경력요약}으로, 특히 {관련 역량}에 강점이 있습니다.

{기업}의 {구체적 제품/서비스}에 대해 평소 관심이 많았는데,
해당 포지션에 대해 좀 더 이야기 나눌 수 있다면 좋겠습니다.

편하신 시간에 잠깐 대화 가능하시면 감사하겠습니다.
```

### 2. PM 리드/동료에게 (Hiring Manager)

```
안녕하세요, {이름}님.

{기업명}에서 {제품/서비스} 관련 PM으로 활동하고 계신 것을 보고 연락드립니다.
저도 {관련 도메인}에서 PM으로 일하고 있는데, {구체적 관심 포인트}에 대해
이야기 나눌 수 있다면 좋겠습니다.

{기업}의 {최근 기능/변화}가 인상적이었는데,
커피챗이나 짧은 통화 가능하시면 좋겠습니다.
```

### 3. 커넥션 요청 메시지 (짧은 버전)

```
안녕하세요, {이름}님.
{기업명}의 {분야} PM으로 활동하고 계신 것을 보고 커넥트 요청드립니다.
저도 같은 분야에서 일하고 있어 인사이트를 나누면 좋겠습니다.
```

## 실행 절차

1. 사용자로부터 타겟 정보를 받습니다:
   - 기업명, 직무명
   - (선택) 메시지 보낼 사람의 이름/직함
2. 기업과 직무에 대해 WebSearch로 최신 정보를 수집합니다.
3. cv.md에서 관련 경험을 추출합니다.
4. 메시지 유형에 맞는 초안을 생성합니다.
5. 한국어 비즈니스 톤에 맞게 다듬습니다.

## 윤리 규칙

- 메시지는 초안입니다. 사용자가 검토 후 직접 전송합니다.
- 허위 경력이나 과장된 표현을 사용하지 않습니다.
- 스팸성 대량 메시지를 권장하지 않습니다.
- 한 기업당 1-2명에게만 연락하는 것을 권장합니다.
