# 이력서 PDF 생성 (pdf)

이 모드는 JD에 맞춤화된 한국식 이력서 PDF를 생성합니다.

## 사전 조건

- `cv.md` — 사용자 이력서 원본 (한국어)
- JD URL 또는 텍스트 — 타겟 공고

## 실행 절차

### 1. JD 분석

JD에서 핵심 키워드를 15-20개 추출합니다:
- 필수 역량 / 우대 역량
- 도메인 키워드
- 기술 스택 / 도구
- PM 방법론 (애자일, 스크럼, 데이터 드리븐 등)

### 2. 언어 및 형식 감지

- **언어**: 한국어 기본. JD가 영문이면 영문 이력서 생성.
- **용지**: A4 (한국 표준)
- **폰트**: Pretendard (한글 최적화 폰트)

### 3. 이력서 맞춤화

`cv.md`를 기반으로 JD에 맞게 재구성합니다:

**Professional Summary (프로필 요약):**
- JD 키워드를 자연스럽게 포함하여 3-4문장으로 재작성
- 기존 경험을 재구성, 절대 없는 경험을 만들어내지 않음
- PM 아키타입에 맞는 톤 (Growth PM이면 지표 중심, Consumer PM이면 UX 중심)

**경력 사항:**
- 가장 관련성 높은 프로젝트 3-4개를 상위로 배치
- 각 프로젝트의 불릿 포인트를 JD 키워드에 맞게 재정렬
- 정량적 성과를 강조 (MAU, 전환율, 매출 등)

**핵심 역량:**
- JD에서 추출한 키워드로 6-8개 역량 구성
- 기술적 역량 + PM 역량을 균형 있게 배치

**학력/자격:**
- cv.md에서 그대로 가져오기

### 4. HTML 렌더링

`templates/cv-template.html` 템플릿을 사용하여 HTML을 생성합니다.

**디자인 원칙:**
- 깔끔하고 전문적인 한국식 이력서 레이아웃
- Pretendard 폰트 (본문 400, 제목 700)
- 단일 컬럼 레이아웃 (ATS 친화적)
- 색상: 진한 네이비(#1a1a2e) + 포인트 블루(#4361ee)
- 여백: 상하 20mm, 좌우 25mm

### 5. PDF 생성

```bash
node generate-pdf.mjs --input /tmp/cv-rendered.html --output output/이력서_기업명_직무명.pdf
```

Playwright Chromium headless로 A4 PDF를 생성합니다.

## ATS 최적화 규칙

- 단일 컬럼 레이아웃 (멀티 컬럼은 ATS가 읽기 어려움)
- 표준 섹션 제목 사용 (경력사항, 학력, 핵심역량 등)
- 이미지/아이콘 최소화
- 텍스트 기반 (PDF 내 텍스트 선택 가능해야 함)
- JD 키워드를 자연스럽게 분산 배치

## 윤리 규칙

- **절대 없는 경험을 만들어내지 않습니다.** cv.md에 있는 경험만 사용합니다.
- 기존 경험을 JD에 맞게 "재구성"하는 것은 OK, "날조"는 절대 NO.
- 정량적 성과는 cv.md에 기재된 수치만 사용합니다.
- 매번 cv.md를 런타임에 읽습니다. 하드코딩 금지.

## 출력

1. PDF 파일: `output/이력서_{기업명}_{직무명}.pdf`
2. 콘솔 요약:
```
=== 이력서 PDF 생성 완료 ===
기업: 카카오
직무: Product Manager, 카카오톡
키워드 반영: 18/20개
파일: output/이력서_카카오_PM카카오톡.pdf
```
