# 자기소개서 자동 작성 (cover-letter)

이 모드는 한국 채용 공고에 맞는 자기소개서 초안을 생성합니다.

## 한국 자기소개서 특징

한국 자기소개서는 서구권의 Cover Letter와 다릅니다:
- **문항 기반**: 기업이 제시하는 문항에 각각 답변 (보통 3-5문항)
- **글자 수 제한**: 문항당 500-1000자 내외
- **대표적 문항 유형**:
  1. 지원동기 / 왜 이 회사인가
  2. 직무 관련 경험 / 역량
  3. 입사 후 포부 / 기여할 수 있는 점
  4. 협업/갈등 해결 경험
  5. 성장 경험 / 실패에서 배운 점

## 사전 조건

- `cv.md` — 사용자 이력서
- `career-description.md` — 경력기술서
- JD URL 또는 텍스트 — 타겟 공고
- (선택) 자기소개서 문항 — 기업이 제공하는 구체적 문항

## 실행 절차

### 1. 문항 수집

사용자에게 자기소개서 문항을 요청합니다:
- 기업 채용 페이지에서 자소서 문항을 복사해서 붙여넣기
- 문항이 없으면 표준 문항 세트를 사용

### 2. JD + 기업 분석

- JD에서 핵심 요구사항 추출
- 기업의 미션, 비전, 핵심 가치 조사 (WebSearch)
- 기업의 최근 뉴스, 제품 출시, 전략 방향 조사
- PM 직군에서 특별히 중요하게 보는 역량 파악

### 3. 문항별 초안 작성

각 문항에 대해:
1. cv.md와 career-description.md에서 관련 경험을 찾습니다.
2. STAR 형식으로 구조화합니다.
3. 기업의 가치/문화와 연결짓습니다.
4. 글자 수 제한을 준수합니다.

**작성 원칙:**
- 구체적인 숫자와 사례로 뒷받침 (추상적 표현 지양)
- 기업의 제품/서비스에 대한 이해를 보여줌
- PM으로서의 사고방식을 드러냄 (문제 정의 → 가설 → 실행 → 측정)
- 진솔한 톤 유지 (과장 금지)

### 4. 검증 및 수정

- 각 문항 글자 수 확인
- cv.md에 없는 경험이 포함되지 않았는지 검증
- 문항 간 내용 중복 최소화
- 기업/직무 특화 내용이 충분한지 확인

## 표준 문항 세트 (기업 문항이 없을 때)

1. **지원동기** (800자): 왜 이 회사, 이 직무에 지원하는가
2. **직무 역량** (800자): PM으로서 가장 자신 있는 역량과 관련 경험
3. **문제 해결** (600자): 복잡한 문제를 해결한 경험
4. **협업** (600자): 다양한 직군과 협업하여 성과를 낸 경험
5. **성장** (500자): 실패에서 배우고 성장한 경험

## 윤리 규칙

- cv.md/career-description.md에 있는 경험만 사용합니다.
- 기업에 대한 정보는 공개된 정보만 사용합니다.
- **초안을 생성할 뿐, 최종 제출은 사용자가 직접 합니다.**
- 과장이나 거짓 표현을 하지 않습니다.
- "AI가 작성했다"는 느낌이 나지 않도록 자연스럽게 작성합니다.

## 출력

각 문항의 초안을 마크다운으로 출력합니다:

```markdown
# 자기소개서 초안 — {기업명} {직무명}

## 1. 지원동기 (782/800자)
[초안 내용]

## 2. 직무 역량 (756/800자)
[초안 내용]

...

---
⚠️ 이 초안은 AI가 생성한 것입니다. 반드시 본인의 목소리로 수정한 후 제출하세요.
```
